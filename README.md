# 都道府県大戦

**47の国、ひとつの日本。**

47都道府県が独立勢力となる、国家運営・領土拡大シミュレーションゲームです。

## 世界観とデザイン
- 巻物・古地図を思わせる和紙色、紙の質感、墨色と落ち着いた差し色。
- タイトル・都道府県名・地域名・基本情報の見出しや数値にGoogle Fonts「佑字 肅」を使用。長い説明や操作欄は可読性を優先して明朝系フォントを併用。
- 全国統一時は画面中央に「勝利！」と「天下統一達成」を大きく表示し、達成ターンを示す専用演出を表示。
- 日本地図を主役に、勢力色・征服地・選択中の県を識別。
- PCとスマートフォンの両方に対応するレイアウト。

## 現在の実装
- 47都道府県から開始国を選択。
- 陸上隣接・橋梁・海峡・航路を使った攻撃と移送。
- 攻撃先を選ぶと、攻撃元・成功率の目安・派遣兵力を表示。
- 農業・工業・サービス・経済・人口・安定度に応じた成長。人口・経済の成長率を引き上げ、各産業の相互作用を強化。農業は食料供給と人口・経済成長、工業は経済・兵力、サービスは人口・経済・各分野の成長を後押し。成長率には上限を設け、急激なインフレを抑える。
- AI勢力の成長と戦闘。プレイヤーとAIは共通の戦闘解決処理を使用。
- 自国領を経由して到達できる範囲への兵力移送。
- 全国統一・滅亡のゲーム終了状態。全国統一時には佑字肅の勝利演出を表示し、達成ターンを記録。
- バージョン付きセーブデータと旧V2データの読み込み互換。
- 地図SVGの再試行、47県コード・重複コードの検査。
- 起動時の内部検査（47県、陸上隣接の相互性、特別接続）。
- ゲームデータとゲーム処理を `game-data.js` / `game.js` に分離。

## データについて
人口・経済・農業・工業・サービス等の初期値は、現段階ではゲームバランス用の仮データです。公的統計をそのまま転記した実測値ではありません。各能力値はゲーム内の成長計算に利用します。

## 隣接データ
陸上で県境を共有する関係と、橋梁・海峡・航路による特別接続を分離して管理します。ゲーム上の接続関係は実際の交通網を簡略化したものです。特別接続はゲームルール上の移動・攻撃経路を表し、実際の交通運行状況を保証するものではありません。

## 地図データ
都道府県境界の表示には Geolonia japanese-prefectures のSVGを外部読み込みします。地図の取得に失敗した場合は最大3回再試行します。通信環境により地図を表示できない場合があります。地図SVGの県コードが47県と一致しない場合は読み込みを中断します。

## セーブデータ
新しいセーブ形式は `todofukenTaisenSaveV3` です。旧 `todofukenTaisenSaveV2` のデータは検証後に読み込みます。異常なデータは適用せず、既存の保存データを自動削除しません。

## 起動
GitHub Pagesを有効にすると公開サイトとして動作します。Google Fontsと地図SVGの取得にはインターネット接続が必要です。


## 連合・外交機能
連合は一方的なボタン操作では成立せず、連合申出書の提出と相手国の承認を必要とする外交システムとして追加する構想です。
- 申出国が対象国を選び、連合申出書を送る。
- 受諾・拒否は相手国が判断する。AI国家は国力差、共通の敵、国境接触などから受諾を判断する。
- 成立後は相互不可侵とし、同じ敵国に対する共同防衛・共同攻撃を可能にする。
- 連合の脱退・解消は通知と猶予ターンを設け、突然の裏切りを避ける。
- 連合が大きくなりすぎた場合の外交的な警戒や、連合国間の利害対立も将来の拡張候補。

連合申出・AIの受諾判断（国力差・共通の敵・国境接触）・プレイヤーへの申出受諾/拒否・相互不可侵・隣接連合国による戦闘支援・1ターン前の解消通告を実装。さらに連合相手の保有兵力・経済力に応じ、毎ターン兵力（3〜25）と経済力（1〜12）の援助を受ける。援助は自国の代表県（失陥時は兵力の少ない自国領）に加算される。


- 侵攻成功時は、巻物が左から右へ開いて「征服完了」と表示される演出を追加。
- 鹿児島県と沖縄県をフェリー航路で接続。短い県境の代表例を含む隣接関係の内部テストを追加。


### 隣接判定・戦闘ルールの検証
- 陸上で県境を共有する86組を、国土交通省の「隣接する都道府県」一覧と照合して管理。橋・トンネル・航路だけの接続は `SPECIAL` に分離。
- 陸上隣接の相互性、重複、全47県の登録、短い県境の接続を内部検査。
- プレイヤーとAIは同じ派遣兵力算出関数と `resolveBattle` を使用。派遣兵力の消費は戦闘解決内で一度だけ行う。
- 勝利時は派遣兵力を消費。敗北時は派遣兵力に加えて派遣数の65%を追加損耗として適用。
