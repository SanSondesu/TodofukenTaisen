# 都道府県大戦

**47の国、ひとつの日本。**

47都道府県が独立勢力となる国家運営・領土拡大シミュレーションゲームです。

## 世界観とデザイン
- 47都道府県がそれぞれ独立国家として並び立つ。
- 古地図・巻物を思わせる和紙色、紙の質感、墨色と落ち着いた差し色。
- 日本地図を主役に、選択中・自国・他国を色で識別。
- PCとスマートフォンの両方に対応する。

## ゲーム構想
- プレイヤーは47都道府県から1つを選び、残る勢力と競う。
- 人口・経済・農業・工業などの地域特性が成長や兵力生産に影響する。
- 地理的な隣接関係を基礎に勢力拡大と防衛を行う。
- AIも成長し、周辺情勢と国力を踏まえて行動する。
- 将来的に外交、政策、歴史・戦況記録を追加する。

## 現在の実装状況
現在は画面、都道府県選択、仮パラメータ表示、プレイヤー勢力の開始、簡易的なターン成長、端末内セーブの土台です。戦闘、正確な隣接データ、本格的なAI、統計に基づく地域パラメータ、外交・政策は未実装です。表示数値は実際の統計値ではなく開発用の仮データです。

## 地図データ
都道府県境界の表示には Geolonia japanese-prefectures のSVGを外部読み込みする構成です。公開前にデータの利用条件・表示要件を確認します。

## 今後の優先順位
1. 47県コードと地図形状の対応、表示位置・欠落の検証。
2. 陸上隣接と海峡・橋梁などの特別接続を区別した正確な隣接データ。
3. 地域特性に応じた人口・経済・産業・兵力の成長。
4. プレイヤーとAIに共通する戦闘・領土拡大ルール。
5. セーブ/ロード、戦況履歴、外交・政策の拡張。
